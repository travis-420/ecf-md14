  per fit, each with its own seed (`seed = 1000 + k` for start `s<k>`).
- **Start points:** with no prior chain in the output folder, cobaya starts from the params' `ref`.
  The kit's `ref` values are fixed numbers, so repeated starts would be identical. Therefore:
  - **s0** = the unchanged kit `ref` point (for free Σmν: `ref: 0.06`).

  The July certified minimizations used 2 starts: the chain MAP and the kit `ref` point.

  covmats automatically from the existing chains. Σmν is not in these covmats; its step scale comes
  from `proposal: 0.05`.
- **Free-Σmν fits:** `mnu` is removed from the theory `extra_args` and sampled with a flat prior

### Defect found at the registered Σmν lower edge (Σmν = 0.0 exactly)

`fullplanck/tier2/logs/mnu_edge_check.log` and `check_models.log`. cobaya 3.6.2's CAMB wrapper
builds `_base_params` once, from the first point it evaluates, then copies it for every later
call (`cobaya/theories/camb/camb.py`, `CAMB.set`). If that first point has Σmν > 0, the copy
carries `num_nu_massive = 1`. When CAMB's `SetNeutrinoHierarchy` is later called with
`omnuh2 = 0`, it moves all of N_eff into massless species but does not reset
`num_nu_massive`. The result is an extra zero-mass "massive" state: **N_eff = 4.0587** instead
of 3.044.

At the certified ΛCDM point this gives χ² = 17183.94 (instead of 2031.95), and at the
certified ECF point χ² = 16979.96 (instead of 2023.22). On a freshly initialized model, Σmν = 0.0
is correct: N_eff = 3.044 and χ² = 2031.9464 (ΛCDM point) / 2023.2183 (ECF point). χ² is then
identical to 4 decimals at Σmν = 1e-8, 1e-6 and 1e-4 eV. Above zero, the physics is correct
and continuous. Every minimizer start has Σmν > 0, so any evaluation exactly on the registered
lower edge, 0.0, would be corrupted. Fixed-Σmν fits (G1) are unaffected.

### Diagnosis (from the existing outputs only; no further fits were run)

1. **The likelihood stack reproduces the certified results.** At the certified best-fit points the
   stack returns the certified χ² to ≤ 0.0002 (pre-minimizer check above). This session's
   minimizer also reached slightly *lower* minima of the objective it actually minimizes than the
   certified runs did: −log post 986.0064 vs 986.0217 for ΛCDM (−0.0153), 981.9203 vs 981.9394 for
   ECF (−0.0191). 2Δ(−log post) between ECF and ΛCDM is −8.1721 here vs −8.1647 certified, a
   difference of −0.0075.
2. **What failed is reading χ² off a −log-posterior minimizer at the default tolerance.** cobaya
   minimizes −log posterior, which includes the Gaussian τ prior and the A_planck prior. Near the
   minimum the posterior is flat along directions where likelihood χ² trades against the τ prior.
   In fit 1, all five starts lie within 0.078 of the best −log post, yet their χ² spans 0.98
   (2004.78–2005.76). The τ-prior term moves in step: 0.285–0.815, i.e. 0.57–1.63 in χ² units.
   bobyqa with `rhoend: 0.05` (the cobaya default, as used in July) stops anywhere in that flat
   region, so the χ² readout scatters by about ±0.5. That is the same size as the G1 tolerance.
   The certified July χ² values are single minimizer outputs of the same procedure (2 starts each),
   so they carry the same kind of scatter.
3. **Fit 2 also showed one incomplete start** (s1, 1.96 above the best in −log post). That is
   consistent with the H0–τ_ecf degeneracy noted in `RESULTS_FULLPLANCK.md` §3.
